# Computer Vision and Deep Learning Notebooks

Google Colab notebooks for neural-network training and fire-detection experiments.

## Overview

`tran.ipynb` contains neural-network training and feature-data experiments. `yolo_emprove.ipynb` contains fire-detection setup and training experiments with dataset-download steps.

## Repository contents

- [tran.ipynb](tran.ipynb)
- [yolo_emprove.ipynb](yolo_emprove.ipynb)

## Requirements

Google Colab or Jupyter with notebook-specific dependencies; access to the external datasets and files referenced in each notebook.

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/colab.git
cd colab
```

Inspect the source and the compatibility notes below before setting up an execution environment.

## Compatibility and scope

Open notebooks individually and inspect paths, install commands, and required datasets before executing cells. Several paths reference `/content` and Google Drive files that are not included here. Keep personal dataset credentials in the notebook runtime or a secret manager, outside committed files.
